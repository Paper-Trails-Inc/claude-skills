# claude-skills

Where we share the Claude skills and agents we've built as part of re-imagining how a modern payroll & HR company should operate. Everything here is a generic version: no client data, no internal names, nothing tied to one company. Take what is useful, change it, and share it.

## What's inside

Each folder has a `SKILL.md` (add it to Claude as a skill), a `PROMPT.md` (paste it into any Claude chat or Project), and a `README.md`. More are on the way. We add each one here as we publish it.

| Folder | What it does |
| --- | --- |
| [chief-of-staff-in-a-box](chief-of-staff-in-a-box) | Interviews you, lets you name your chief of staff, command center and brand, then builds a full operating system: brain dump, routines, agents register, delegation filter, goals, how you work, management team dashboard and 1:1 pages. |

## How to get it

1. **Download the zip:** use the green Code button, then Download ZIP, and open the folder you want. Zip that folder to upload it as a skill.
2. **Add it as a skill:** in Claude, upload the zip as a skill, then ask for the task in your own words.
3. **Or paste the prompt:** open `PROMPT.md`, copy it into a new Claude chat or Project, and start.

## Before you rely on any of it

These are starting points. The output depends on what you tell them, and it can be wrong. Read every rule, check facts against primary sources, and review anything before it is sent, posted or published. None of these connect to your accounts by themselves.
