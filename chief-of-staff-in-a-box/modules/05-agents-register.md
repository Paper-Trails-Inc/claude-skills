# Module 5: Agents register

An agent here means any routine, scheduled task or helper that runs without {{MY_NAME}} typing every step. {{CHIEF_NAME}} keeps one list of all of them in {{CENTER_NAME}} so nothing runs that nobody remembers.

## Register columns

| Column | What goes in it |
| --- | --- |
| Name | Short and plain (for example, "Daily brief") |
| Job | One sentence. If it takes two, it is two agents. |
| Schedule | When it runs, or "by hand" |
| Reads | Every source it looks at (calendar, inbox, task list, a folder) |
| Writes | Everything it can change. "Nothing, drafts only" is the best answer. |
| Needs approval for | Anything that leaves the building or can't be undone |
| Last run | Date, and "ok", "flagged" or "failed" |
| Status | Active, paused or retired |
| Owner | Who answers for it (usually {{MY_NAME}}) |

## Rules

1. **One job each.** Don't build an agent that does five things.
2. **Read only first.** A new agent reads and drafts for two weeks before it writes anything.
3. **Drafts only.** No agent sends, posts, pays, deletes or publishes. A person does that.
4. **Log every run.** Date, result, what it flagged. A failed run is logged as failed.
5. **Small on purpose.** Aim for five or fewer active agents. Before adding one, ask which one it replaces.
6. **Retire what is not used.** At the 30 day noise audit, anything {{MY_NAME}} did not act on is paused or retired.
7. **Sensitive data stays out.** If an agent would touch anything sensitive, stop and ask the person first.

## Starter agents

Suggest these during Phase 2 and let the person pick:

1. Daily brief
2. Weekly review
3. Monthly cleanup (can fold into the weekly review at first)
4. Quarter review
5. Inbox sweep (optional, read only)
6. Meeting prep (optional, day before 1:1s and team meetings, modules 9 and 10)
7. Lanes (optional, revenue, finance, relationships; run as sections of the routines above, see module 14)

## New agent checklist

Before turning one on, fill this in with the person:

* What problem does it solve, in one line?
* What will it read and write?
* What is the worst thing it could do if it misunderstands?
* How will I know it is working (what will I see)?
* When will I review whether it earned its place (date)?

If any answer is blank, it isn't ready.
