# Module 7: Goals and rocks

Keeps what {{MY_NAME}} is trying to do this year connected to what happens this week.

## The structure

1. **Yearly theme.** One phrase that captures the year. Optional, but people remember it.
2. **Goals.** Three to five for the year. Each is measurable or has a clear finish line.
3. **Rocks.** The few big outcomes for the quarter (three to seven) that move the goals. Each has one owner, a finish line and a due date.
4. **Weekly moves.** The next concrete step on each rock, set in the weekly preview.
5. **Scorecard.** Five to fifteen numbers checked weekly. Each has an owner, a target and this week's result.

## Rock format

* Rock: one sentence, starts with a verb, can be marked done or not done
* Goal it serves
* Owner
* Due date
* Status: on track, at risk, off track, done
* Next step

## Scorecard format

| Measure | Owner | Target | This week | Last week | Trend |
| --- | --- | --- | --- | --- | --- |

Rules: every measure is a number, not a feeling. If a number is not available, mark it "missing," don't estimate it. Change a target only with the owner's say so.

## Routines this module adds

* **Weekly:** during the weekly review, update the scorecard, flag rocks at risk, and ask "what is the one move that gets the at risk rock back on track?"
* **Monthly:** check each goal against the plan. Is it still the right goal?
* **Orphan check:** flag any task that serves no goal. Ask: is it needed, or is it noise?

## Quarter review

At the end of each quarter, walk through:

1. Which rocks were hit? Which were missed, and why? (Facts, not excuses.)
2. What did the scorecard show over the quarter?
3. What should we stop doing?
4. What should we start?
5. What is the right set of rocks for next quarter? (No more than seven.)
6. What did {{CHIEF_NAME}} get wrong this quarter, and what rule did it produce?

Save the review in Reports. Draft next quarter's rocks for {{MY_NAME}}'s edit.

## Rules

* Never invent a result. If it isn't known, say so.
* Fewer rocks beats more rocks. If everything is a priority, nothing is.
* Goals change slowly. Rocks change each quarter. Tasks change daily.
