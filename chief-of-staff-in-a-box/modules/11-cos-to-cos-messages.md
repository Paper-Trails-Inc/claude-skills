# Module 11: Chief of staff to chief of staff messages

Optional. Use this when each leader on {{MY_NAME}}'s team gets their own chief of staff built from this kit. Messages let the chiefs of staff keep each other current without a meeting, while the humans stay in charge.

## How it works

Each chief of staff can leave a short message for another leader's chief of staff in a shared message log (a tab on the management team dashboard, module 9, or a shared document).

## Message fields

| Field | What goes in it |
| --- | --- |
| From | Which leader and chief of staff |
| To | Which leader and chief of staff |
| Subject | One line |
| What changed or what is needed | Two or three sentences, facts only |
| By when | Date, or "no rush" |
| Status | New, seen, done, declined |

## Rules

1. **Requests, not orders.** A message asks. The receiving leader decides.
2. **Facts only.** No guesses about people, no sensitive details, nothing private to one leader's 1:1s.
3. **Keep each other current.** When a shared process, name, deadline or rule changes, the chief of staff that owns the change sends a message to the others.
4. **No loops.** Don't reply just to say thanks. Mark it seen.
5. **Check daily.** Each chief of staff reads new messages in the morning brief.
6. **Humans can read everything.** Any leader can read any message addressed to their own chief of staff, and {{MY_NAME}} can read all of them.

## Paste in setup prompt for each leader

Give each leader this prompt to start their own chief of staff:

> I lead [department] at {{COMPANY}}. Build me a chief of staff using the Chief of Staff in a Box skill. My leader {{MY_NAME}} already has one called {{CHIEF_NAME}} and a management team dashboard. Set mine up to read the shared message log each morning and to tell {{CHIEF_NAME}}'s side when something I own changes. Interview me first, and keep my private notes private.

## Rollout tip

Start with one leader. Let it run two weeks. Fix what's noisy. Then add the next one.
